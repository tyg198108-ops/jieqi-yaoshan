# 节气药膳师 · 专业版

基于《中医药膳营养师》16节专业课程开发的节气药膳食谱SaaS工具。

- 在线预览（静态）：https://tyg198108-ops.github.io/jieqi-yaoshan/
- 源码仓库：https://github.com/tyg198108-ops/jieqi-yaoshan

> 在线版只跑前端。想用完整的「生成席单」（需要后端规则引擎做安全校验），
> 请在本机双击 `启动节气药膳师.bat` 起后端，再打开上面的在线地址即可连上本机后端。

## 功能特点

1. **首页仪表盘**：显示当前节气、养生要点、快速入口、二十四节气总览
2. **九种体质测试**：36道问卷自动判断主体质+兼夹体质，给出食疗建议
3. **智能宴席生成**：选节气+选体质+选特殊人群，按场景一键出单
   - **养生宴（10人席，17道）**：冷菜6（3荤3素）+ 热菜8（虾/鱼/牛羊肉/鸡/蔬菜五类必覆）+ 药膳汤1（标药材配伍与功效）+ 点心或主食1 + 季节茶饮1（标宜忌）
   - **家庭餐**：4菜一汤一饮
   - **商务餐**：2冷 + 4热 + 1汤 + 1饮品
4. **药食同源食材库**：查询食材四气五味、功效、禁忌
5. **安全校验引擎**：自动检测特殊人群禁忌、配伍禁忌
6. **打印导出**：宴席方案可直接打印/导出PDF
7. **专业科学**：中医功效+现代营养学双重标注，合规宣传

## 使用方法

### 方法一：一键启动（推荐）
双击 启动节气药膳师.bat，然后在浏览器打开 http://localhost:8000

### 方法二：直接打开（部分浏览器可能受限）
直接双击 index.html 文件在浏览器中打开即可使用（推荐Chrome/Edge）。
