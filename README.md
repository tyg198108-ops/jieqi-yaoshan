# 节气药膳师 · 专业版

基于《中医药膳营养师》16 节专业课程开发的节气药膳食谱 SaaS。规则引擎自动校验体质、节气、人群与配伍禁忌，按场景生成可用席单。

- 源码仓库：https://github.com/tyg198108-ops/jieqi-yaoshan
- 在线预览（静态）：https://tyg198108-ops.github.io/jieqi-yaoshan/

> 在线版只跑前端。「生成席单」需要后端规则引擎做安全校验，本机双击 `启动节气药膳师.bat` 起后端后，
> 再打开上面的在线地址即可连上本机后端。

## 功能特点

1. **首页仪表盘**：当前节气、养生要点、二十四节气总览
2. **九种体质测试**：36 道问卷判主体质 + 兼夹体质，给食疗建议
3. **按场景生成席单**：引擎按场景出结构，前端不做裁剪
   - **养生宴（10 人席，17 道）**：冷菜 6（3 荤 3 素）+ 热菜 8（虾 / 鱼 / 牛羊肉 / 鸡 / 蔬菜五类必覆、技法错开）+ 药膳汤 1（标药材配伍）+ 点心或主食 1 + 季节茶饮 1（标宜忌）
   - **家庭餐**：4 菜一汤一饮（6 道）
   - **商务餐**：2 冷 + 4 热 + 1 汤 + 1 饮品（8 道）
4. **药食同源食材库**：四气五味、归经、功效、禁忌，标注是否在卫健委 106 种目录内
5. **安全校验引擎**：block（禁用）/ warn（慎用）/ tip（提示）/ good（适宜）四级，附规则出处
6. **我的方案**（云端）：匿名登录即可保存席单、跨会话查看历史，可选绑手机号跨设备同步
7. **打印导出**：席单可直接打印 / 导出 PDF

## 使用方法

### 本机运行（推荐）

双击 `启动节气药膳师.bat`，浏览器打开 http://127.0.0.1:8000

> 直接双击 `index.html` 也能打开并浏览数据，但 `file://` 协议下无法调后端，「生成席单」会失败，页面会明确提示。

### 部署到线上（腾讯云开发）

完整步骤见 **[部署上线手册.md](部署上线手册.md)**，主干是：

```bash
python _build_cloud.py        # 构建 dist/cloudfunction 与 dist/web
双击 部署到腾讯云.bat          # 部署后端云函数 + 前端静态站
```

架构要点：**后端是无状态纯计算**，不碰用户数据，所以不用写鉴权；用户数据与登录交给云开发数据库 + 内置匿名登录，
靠集合权限「仅创建者可读写」隔离。

## 数据口径

| 项 | 数量 | 说明 |
|---|---|---|
| 节气 | 24 | 含当季食材、饮食注意、民俗 |
| 体质 | 9 | 王琦九种体质标准，含 36 道测试题 |
| 食材 | 207 | 其中药食同源按卫健委 106 种目录标注 |
| 菜品 | 154 | 含金陵冷碟 21 道等地方菜 |
| 配伍规则 | 13 类 | 十八反十九畏、人群禁忌、七情合和 |

## 目录结构

```
index.html            单文件入口（本地形态由后端托管）
app-data.js           前述数据的静态副本，后端不可用时降级用
js/                   api / role / pages / cloud / cloud-panel
css/                  样式
vendor/               Vue 3 + Element Plus 本地化依赖（断网可用）
backend/
  main.py             FastAPI 应用工厂（本地 / 云端两形态）
  cloud_entry.py      云函数入口（部署时复制为 index.py）
  cloud_adapter.py    API 网关事件 ⇄ ASGI，纯标准库实现
  db_bootstrap.py     从 JSON 自举数据库（云函数冷启动用）
  engine/             matcher / validator / generator / taxonomy
  data/               *.json 是唯一事实源
```

## 环境变量

| 变量 | 默认 | 用途 |
|---|---|---|
| `YS_API_ONLY` | 空 | 设为 1 只暴露 `/api/*`（云端形态） |
| `YS_DB_PATH` | `backend/yaoshan.db` | 数据库路径，云端必须为 `/tmp/yaoshan.db` |
| `YS_DB_REBUILD` | 空 | 设为 1 强制从 JSON 重建数据库 |
| `YS_CORS_ORIGINS` | `*` | 逗号分隔，收紧跨域白名单 |

## 自检命令

```bash
python backend/_cf_selftest.py     # 云函数全接口（含三场景生成）
python _compliance_scan.py         # 合规扫描：医疗宣称词必须 0
python _regress.py                 # 11088 组合分级回归，比对基线
```

前端 jsdom 回归（需先起后端）：

```bash
node _smoke.js                     # 首屏 + 角色差异
node _nav_test.js                  # 导航与历史
node _scene_banquet_test.js        # 养生宴 17 道结构
```

## 合规声明

健康类内容面向公众，本项目已做三层处理：

- 数据侧与文案侧定期跑 `_compliance_scan.py`，医疗宣称词必须为 **0**
- 结果页固定输出免责声明，页脚有完整版本说明
- 规则引擎的 block / warn 是**风险提示**，不等于疗效宣称

本工具给出饮食参考建议，不构成医疗诊断、治疗或用药建议，不能替代医师诊疗。
